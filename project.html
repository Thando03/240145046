Software Engineering Project

Ibotwe Cafeteria Ordering System

A smarter, faster way for students to order food on campus.

Online Orders Fast Pickup Campus Delivery

Project Description

This project is a software application designed to reduce long queues in the campus cafeteria by allowing students to order food online. Students can choose to either pick up their food at the cafeteria or have it delivered to their location on campus.

Problem Statement

Students experience long waiting times at the cafeteria, especially during peak hours, which leads to wasted time and missed classes.

Solution

  • View available meals
  • Place orders in advance
  • Select pickup or delivery options
  • Avoid standing in long queues

Planned Technologies

  • Frontend: HTML, CSS
  • Backend: Python
  • Database: MySQL
  • Version Control: Git/GitHub
